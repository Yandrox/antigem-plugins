# Paletas / Palettes

## ES — presets incluidos

`sunset`, `ocean`, `mint`, `retro`, `candy`, `noir`, `forest`, `flow`.

Pasa `{"name":"ocean"}` a `asset_palette` o `{"palette":"ocean"}` a `asset_background`.

### Armonías desde un color base

| `harmony` | Resultado |
| --- | --- |
| `analogous` | Colores vecinos en la rueda; armonioso y seguro. |
| `complementary` | Base + opuesto; alto contraste para CTA. |
| `triadic` | Tres colores equidistantes; muy vivo. |
| `tetradic` | Cuatro colores en rectángulo; útil para infografía. |
| `monochrome` | Una sola familia con luminosidad variable; elegante y legible. |
| `split` | Base + dos colores junto a su complemento; contraste suave. |

`count` acepta de 2 a 12. `format` puede ser `hex`, `rgb` u `hsl`. La respuesta incluye `cssVars` para pegar en una mini app.

## EN — bundled presets

`sunset`, `ocean`, `mint`, `retro`, `candy`, `noir`, `forest`, `flow`.

Pass `{"name":"ocean"}` to `asset_palette` or `{"palette":"ocean"}` to `asset_background`.

### Harmonies from a base color

| `harmony` | Result |
| --- | --- |
| `analogous` | Neighbouring hues; harmonious and safe. |
| `complementary` | Base plus its opposite; high contrast for CTAs. |
| `triadic` | Three evenly spaced hues; vivid. |
| `tetradic` | Four hues in a rectangle; useful for infographics. |
| `monochrome` | One hue with variable lightness; elegant and readable. |
| `split` | Base plus two hues beside its complement; softer contrast. |

`count` accepts 2 to 12. `format` can be `hex`, `rgb` or `hsl`. The response includes `cssVars` ready to paste into a mini app.
